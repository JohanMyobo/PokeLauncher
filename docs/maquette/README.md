# Maquette V1

Trois écrans, en version interactive sur le canvas Claude (lien privé, dans la fiche Notion) :

1. `Main.dc.html` : bibliothèque classée par génération, avec le bloc « Reprendre »
2. `Fiche.dc.html` : fiche d'un jeu (exemple : Platine), avec progression, variantes et sauvegardes
3. `Reglages.dc.html` : dossier des ROMs, émulateurs, sauvegardes, outils de modification

Les jaquettes sont des aplats de couleur par version (pas d'images officielles).
Les données affichées (progression, dates, ROMs manquantes) sont des exemples.
